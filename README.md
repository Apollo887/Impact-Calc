The Physics Behind It
Impact force is calculated using the formula:

Force = (Mass × Velocity) / Time

This comes from Newton's second law. When something moving hits an object and slows down, the force of that impact depends on how heavy it is, how fast it was going.

Units:

Mass (kg) - how heavy the object is
Velocity (m/s) - how fast it was moving before impact
Time (s) - how long the collision takes to happen.
